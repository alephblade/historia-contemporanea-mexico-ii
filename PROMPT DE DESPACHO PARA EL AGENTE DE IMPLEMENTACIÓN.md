# Prompt de despacho para el agente de implementación

Trabaja en el proyecto de Historia Contemporánea de México II de la Universidad Autónoma Chapingo. Tu objetivo es construir y probar localmente la primera versión estática del repositorio educativo con Astro, preparada para GitHub Pages.

Antes de modificar archivos, lee `BRIEF RECTOR PARA LA IMPLEMENTACIÓN DEL REPOSITORIO WEB.md` y sigue su jerarquía documental, alcance, restricciones, rutas, controles y criterios de aceptación. Este brief es la referencia operativa principal de esta tarea.

Conserva los registros canónicos, fichas pedagógicas, orientaciones y fuentes existentes. Genera proyecciones públicas deterministas; no dupliques manualmente metadatos en componentes, no publiques fuentes locales de terceros y no simules recursos derivados planeados como publicados. Implementa las rutas de lecturas, unidades y orientaciones, incluida `ORI_HIST2_U3_TRAMA_01`; valida el corpus antes de construir y documenta toda decisión o bloqueo institucional.

No actives GitHub Pages, no crees un remoto de GitHub, no uses CMS, OAuth, Google Sheets ni datos de producción sin autorización expresa. Al terminar, entrega el sitio construible, pruebas y CI, documentación de operación y un informe de resultados.
