# Archivo histórico del proyecto

Esta carpeta preserva documentos e insumos que ya no deben emplearse como referencia operativa. Se conservan para mantener la trazabilidad de las decisiones y facilitar, si fuera necesario, la consulta de antecedentes.

## Regla de uso

Los archivos aquí contenidos no se editan ni alimentan los registros canónicos, las fichas pedagógicas ni una futura publicación. Para el trabajo vigente deben consultarse el **Instrumento rector de extracción, verificación y curaduría de lecturas**, la **Especificación del registro canónico de lecturas**, el **Vocabulario controlado** y la **Ficha pedagógica del recurso**.
