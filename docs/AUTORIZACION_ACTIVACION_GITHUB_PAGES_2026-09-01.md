**Responsable que transmite la autorización:** Arnoldo Prado

## Constancia operativa

Arnoldo Prado informó que completó el recorrido manual del sitio mediante teclado. Reconoció que pueden persistir detalles menores y autorizó publicar la versión actual bajo el entendimiento expreso de que el repositorio continuará sujeto a mejora, actualización y depuración. La publicación inicial tiene además el propósito inmediato de servir como constatación durante una fase administrativa interna.

Esta constancia autoriza activar GitHub Pages para el repositorio público `alephblade/historia-contemporanea-mexico-ii`, desde la rama `main`, mediante GitHub Actions y con la ruta base `/historia-contemporanea-mexico-ii`.

## Límites conservados

La autorización:

- no promueve los registros, fichas u orientaciones más allá de `en_revision`;
- no presenta el sitio como versión académica definitiva;
- no autoriza publicar copias locales de fuentes de terceros;
- no habilita CMS, OAuth, Google Sheets, analítica, autenticación ni datos de producción; y
- mantiene CC BY-SA 4.0 para el contenido académico original, MIT para el código original y las exclusiones documentadas para materiales y signos de terceros.

## Compuerta de despliegue

La activación queda condicionada a que la construcción con `SITE_URL=https://alephblade.github.io` y `BASE_PATH=/historia-contemporanea-mexico-ii` apruebe las mismas validaciones de corpus, proyección, tipos, enlaces, accesibilidad estructural y exclusión de fuentes usadas localmente y en CI.

El flujo remoto `Publicar en GitHub Pages` concluyó correctamente en la ejecución `33493202408`, sobre el commit `dd648aded0bf3fe1dbd163d1dcf51816d2fe1432`.

La URL `https://alephblade.github.io/historia-contemporanea-mexico-ii/` respondió por HTTPS con estado 200. También se verificaron el catálogo de lecturas, una orientación con ruta profunda y el logotipo institucional. La publicación inicial conserva el carácter evolutivo y los límites declarados en esta constancia.
